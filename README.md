# Taylor-Swift-Data-Science-Project
This project was conducted to better understand the trends and statistics of Taylor Swift's discography.
The files included are from Excel and Python.

When downloading the files know that not all code that is included was used in this analysis.
The graphs/code used were the average danceability bar chart from the Homework 3 Excel sheet, the chi squared test from the Homework 6 Python code, the machine learning results for explicitness and characteristics from the Homework 9 Python code, and all of the graphs included in the Final Project Python code.

When downloading this code, be sure to run all cells and take into the account with the machine learning algorithms that the train-test splits may change the accuracy of the model when re-running the code. Additionally, use any comments as guides for how the analysis was preformed and what the takeaways were.

This code could be helpful to understand musical trends through Taylor Swift's discography. While much was done with this data through this project, more can always be done!
